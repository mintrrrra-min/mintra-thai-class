MINTRA THAI CLASS — Offline-ready package

สิ่งที่เพิ่มในชุดนี้
1) PWA shell: manifest + service worker เพื่อให้เปิดหน้าแอปที่เคยโหลดแล้วได้เมื่อออฟไลน์ (ต้องติดตั้งผ่าน HTTPS/GitHub Pages และเปิดออนไลน์ครั้งแรกก่อน)
2) ปุ่ม “ย้อนกลับล่าสุด” เก็บประวัติการบันทึกย้อนหลังสูงสุด 15 จุดต่อห้องเรียนในเบราว์เซอร์เครื่องนั้น
3) เก็บข้อมูลด้วย localStorage เหมือนระบบเดิม ไม่มีการย้ายหรือลบข้อมูลเดิมโดยอัตโนมัติ

ข้อจำกัดสำคัญ
- ชุดนี้ยังไม่เชื่อม Google Sheets และยังไม่ซิงก์ข้าม iPad/คอมพิวเตอร์
- ออฟไลน์ใช้ได้เฉพาะอุปกรณ์/เบราว์เซอร์ที่เปิดเว็บไซต์ออนไลน์อย่างน้อยหนึ่งครั้งและ service worker ติดตั้งสำเร็จ
- ข้อมูลที่แก้ไขออฟไลน์จะอยู่ในเครื่องนั้น ไม่ถูกส่งไปอีกเครื่องจนกว่าจะพัฒนาระบบซิงก์ที่ปลอดภัย
- อย่าแทนที่เว็บไซต์จริงจนกว่าจะสำรองข้อมูลและทดสอบไฟล์นี้ด้วยข้อมูลทดลอง

ติดตั้งบน GitHub Pages
1) สำรองไฟล์ index.html เดิมและดาวน์โหลดข้อมูลสำรองจากแอป
2) ใน repository ของ GitHub Pages ให้อัปโหลดไฟล์ทั้ง 5 รายการนี้ไว้ในโฟลเดอร์เดียวกับ index.html เดิม: index.html, sw.js, manifest.webmanifest, icon-192.png, icon-512.png
3) Commit changes แล้วเปิดเว็บไซต์ผ่าน HTTPS รอโหลดหน้าเว็บหนึ่งครั้ง
4) ทดสอบเปิด/ปิดอินเทอร์เน็ตและปุ่มย้อนกลับด้วยข้อมูลทดลองก่อนใช้ข้อมูลจริง
5) บน iPad: เปิดเว็บไซต์ใน Safari ขณะออนไลน์ > Share > Add to Home Screen

ถ้าข้อมูลเดิมของครูอยู่ใน localStorage ของเว็บไซต์เดิมบนเครื่องเดียวกัน การอัปเดตไฟล์หน้าเว็บที่ URL เดิมจะยังคงข้อมูลเดิมไว้ แต่ต้องไม่ล้าง Website Data ของ Safari/Chrome.
